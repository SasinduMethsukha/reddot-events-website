# Reddot Events - Official Company Website

A complete, high-performance, modern web application built for **Reddot Events** — Sri Lanka's end-to-end event management and technical production company founded by **Randesh Daluwatte** and **Sasindu Methsukha**.

---

## 🌟 Brand Core Message
> *"One team. One event. From planning to production to execution. Reddot Events connects the dots between event management, logistics and technical production to deliver seamless events."*

---

## 🚀 Key Features & Interactive Modules

1. **Light Antigravity Theme & Full-Hero Particle Engine**:
   - Signature Red Dot particle physics background (`#E60026`) covering the entire Home section canvas (`z-index: 0` underneath text and cards).
   - Slow, ultra-smooth floating drift with interactive cursor repulsion that clears space for the mouse.

2. **Leadership Spotlight**:
   - Spotlighting partners **Randesh Daluwatte** (Operations & Strategic Planning) and **Sasindu Methsukha** (Technical Production & AV Engineering).

3. **7 Core Services Breakdown**:
   - Event Planning & Management
   - Event Coordination & On-Ground Execution
   - Vendor & Logistics Management
   - Audio Production (Line Array systems, Midas/Yamaha digital mixers, wireless mics)
   - Visual Production (P2/P3 high-res indoor & outdoor LED walls, moving head lighting rigs)
   - Video Production & Photography (4K multi-cam live broadcast & drone cinematography)
   - Event Technical Production & Heavy Staging (Aluminium box trussing, main & generator backup power, pyrotechnics)

4. **Interactive Event Scope Estimator with Custom Write-In Options**:
   - Prospective corporate and private clients can select event type (or type a custom event), expected attendance (or enter exact count), and production modules (including custom write-in items).
   - Generates a 1-click **Direct WhatsApp Inquiry** pre-filled with their exact event specifications.

5. **Filterable Portfolio & Case Studies**:
   - Categorized gallery (`Corporate`, `Product Launch`, `Concerts & Shows`, `Private & Weddings`).

6. **Fragmented vs. Reddot Comparison**:
   - Visual side-by-side table illustrating the financial and operational advantage of a unified in-house team.

7. **FAQ Accordion & Lead Generation Contact Hub**:
   - Accordion for common event planning questions in Sri Lanka.
   - Complete inquiry form with instant toast notification.
   - Official company email: `reddotcreative.events@gmail.com`
   - WhatsApp quick chat integration, hotline numbers (`+94 77 XXX XXXX`), and Sri Lanka island-wide coverage details.
